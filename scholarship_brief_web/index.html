A biomimetic, pipeline-level defense framework that wraps LLM agents inside a multi-stage quality-control loop to resist indirect prompt injection while preserving benign utility.

Research Background

The Agent Safety Gap

Modern LLM agents handle emails, calendars, payments, and documents. Public benchmarks like AgentDojo and HarmBench show that a single malicious instruction hidden in a tool output or web page can hijack the entire execution loop.

⚠️

Prompt-Level Defenses Are Fragile

System prompts, spotlighting, and repetition rely on the model's own judgment. They collapse when attackers adapt payload style or exploit instruction hierarchy.

🛡️

Peripheral Filters Miss Multi-Turn Attacks

Per-message classifiers and tool allow-lists cannot catch attacks spread across multiple tool calls or reusing tools the benign task legitimately needs.

🔒

We Need Structural Harnesses

Safety must be a property of the whole agent execution pipeline—input parsing, planning, gating, and action—not a single model decision or isolated filter.

System Design

High-Level Architecture

The harness wraps a standard LLM agent loop (Plan → Review → ToolCall) in a four-stage, fail-closed quality-control pipeline inspired by biological checkpoint pathways.

Structural Pre-processing

Heterogeneous content is parsed into semantically meaningful chunks. Controlled transformations surface order- or context-dependent inconsistencies before planning.

🚪

Risk-Aware Gate

Provenance state is tracked across the execution trace. Scrutiny escalates when untrusted content is carried forward, suspicious patterns repeat, or the plan deviates from the user goal.

✂️

Scoped Sanitization

After passing the gate, transit-only metadata and routing hints are removed so that injected cues cannot survive into the trusted execution context.

✅

Trusted Execution

Tool calls are issued only from the sanitized context. All side effects are logged, creating an auditable trail for debugging and red-teaming.

Engineering Workflow

Evaluation Pipeline

A reusable, model-agnostic workflow built around public benchmarks. Results are only compared on batches where the no-defense baseline is genuinely under attack pressure.

1

Task Sampling

Select representative anchor tasks from AgentDojo suites: banking, workspace, travel, and Slack.

2

Attack Sweep

Systematically pair each task with multiple injection families, including persona variants, education framing, and direct tool hijacking.

3

Stress Validation

Verify that the unprotected baseline is vulnerable. If the no-defense baseline is already safe, the batch is not used for primary comparison.

4

Defense Comparison

Run identical (task, attack) pairs under no defense, prompt-level baselines, a learned detector, and the biomimetic harness.

🔥

Stress Gate

Is the no-defense baseline under enough attack pressure? Batches that fail here are excluded from the main comparison but kept as architecture checks.

🛡️

Security Gate

Did the injection succeed under the defense? A defense must block harmful side effects to pass.

⚖️

Utility Gate

Did the benign task still complete? A fail-closed system must be measured on both axes: safety and retained utility.

⚙️

Declarative Configs

Model-Agnostic Backends

Expanded Scope

Large-Scale Project Framework

The current seed experiments are a proof of concept. The same harness and evaluation framework can be scaled into a comprehensive AI safety research platform.

Completed

Phase 1: Core Harness & AgentDojo Validation

Implement the four-stage pipeline, run the seed benchmark on two model backends, and establish the stress-gated evaluation methodology.

In Progress

Phase 2: Expanded Attack Surface

Integrate HarmBench, custom enterprise red-teaming tasks, and multi-modal injections (images, documents, audio transcripts).

Future

Phase 3: Adversarial Stress Testing

Develop an adaptive attacker that optimizes against the harness, train a stronger detector with adversarial examples, and measure robustness under distribution shift.

Future

Phase 4: Production Integration

Package the harness as a middleware layer for LangGraph / LlamaIndex agents, add real-time audit dashboards, and open-source the evaluation framework.

Future

Phase 5: Safety Certification

Define formal threat models, prove harness invariants under bounded assumptions, and align with emerging AI safety standards and regulation.

Why This Matters

As LLM agents move from demos to production, the attack surface shifts from the model itself to the agent execution loop. This project contributes a reusable engineering framework for building structural, fail-closed harnesses around LLM agents—so that future defenses can be evaluated and deployed without rewriting the safety layer from scratch.
