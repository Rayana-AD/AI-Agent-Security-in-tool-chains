\section{Discussion and Conclusion}
\label{sec:discussion}

BioHarness is a principle-constrained multi-stage continuity protocol: understand-then-transfer (Fold), elastic channel authorization (Gate), and minimal signal cleavage (Cleave), closed by carry state. On stress-conditioned AgentDojo tasks, it achieves 98.1\% (DeepSeek) and 95.8\% (Llama) macro security against Spotlighting and learned detectors, while raising DeepSeek utility under both condition-macro and episode-weighted aggregation. Llama utility remains near the model's undefended headroom. Ablations align with the principles: metadata repair (cleavage that keeps cargo) drives utility; feature reordering and goal-aligned authorization (Fold coherence + Gate elasticity) provide security.

\paragraph{Aggregation sensitivity.}
Condition-macro and episode-weighted estimands agree on direction for DeepSeek: BioHarness utility is 92.6\% (macro) and 87.5\% (episode-weighted) versus 67.6\% and 79.7\% without defense. Banking-heavy weighting shrinks the absolute gap but does not reverse it. We treat security as near-ceiling under both estimands.

\paragraph{Reflection as soft control.}
As introduced in the method, reflective Fold provides soft continuity feedback---often softening lockdown for safe or read-like actions---rather than acting as a hard attack classifier. Empirical results confirm this: removing reflection lowers live DeepSeek utility from 94.4\% to 79.2\% while security stays high, as downstream feature reordering absorbs the blocking burden. It is an upstream signal, not a standalone ASR booster.

\paragraph{Limitations.}
The contribution is a principle-constrained multi-stage transport protocol rather than a new foundation model or single learning algorithm. Claims cover standard AgentDojo framings, not all smuggle morphologies or adaptive adversaries. Live drop-one ablation is currently DeepSeek-only. We view these as next measurements, not reasons to discount the end-to-end security result.

\subsection{Conclusion}

We presented BioHarness, a continuity harness in which Fold, Gate, and Cleave each instantiate a protein-translocation principle for regulating untrusted information at tool boundaries. Across two model backends, it delivers near-complete security on stressed AgentDojo conditions while retaining competitive utility relative to standard defenses. Ablations locate utility mainly in elastic minimal repair and security in coherence checking plus goal-aligned authorization; reflection supplies soft understandability feedback for Gate. Boundary-aware transport protocols---not only input classifiers---remain a practical path to safer tool-using agents.
